This talk dives into transformer inference engines and the engineering choices behind fast generation. We begin with the anatomy of a transformer, revisiting attention, feed forward blocks, and the role of the model context window. From there we look at inference in two phases, the prompt phase and the decode phase, and why they stress hardware differently. We cover key value caching, how it saves recomputation, and how memory grows as sequences get longer. We then compare batching strategies: static batching for throughput, continuous batching for latency, and the tradeoffs each introduces. Quantization gets a dedicated section, explaining how weights and activations can be stored in lower precision without destroying quality. We finish with measurement, discussing tokens per second, time to first token, and how to benchmark a serving stack honestly. Throughout, we connect each technique back to the model behaviour that a user actually feels.
